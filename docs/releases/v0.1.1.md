# UK Tax Tracker 0.1.1

A security update for the container image. The app itself is unchanged, and so are the desktop
installers, the npm package and your data.

## What changed

- **The image no longer includes npm, npx or corepack.** They came with the Node.js base image and
  bring their own dependencies, several of which have published vulnerabilities. The app never runs
  them, so they are removed, and the image is smaller as a result.
- **Debian security updates are applied when the image is built.** This includes the monthly
  rebuild, so a fix Debian publishes reaches the image at the next rebuild instead of waiting for a
  new Node.js base image. This release picks up a fix for `libzstd1`.

## Upgrading

- **Docker and Kubernetes:** if you follow the `0.1`, `0` or `latest` tag, pull the image and
  restart (`docker compose pull && docker compose up -d`, or restart the pod). If you pinned
  `0.1.0`, change the tag to `0.1.1` or `0.1`.
- **Desktop installs and npm:** nothing to do. You can update with the installer if you like, but
  the app is the same.

See [Upgrading](https://github.com/apilbeam101/tax-tracker/blob/v0.1.1/docs/UPGRADING.md) and the
[changelog](https://github.com/apilbeam101/tax-tracker/blob/v0.1.1/CHANGELOG.md).
